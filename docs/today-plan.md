# План следующего этапа

Основание: пять скриншотов photo_*_2026-11-15_13-03-32.jpg и просмотр текущего кода.

1. Репозиторий: рабочий Git находится в publish/soundcloud-rust-client, origin — ArciomKapitonau/soundcloud-rust-client. Открывать эту папку как проект Codex; проверить доступ к GitHub отдельно. Текущая среда не соединяется с API. Не продолжать поддерживать две копии исходников после перехода.
2. Прокрутка: измерить на длинной ленте в обычном и совместимом режимах; проверить стоимость backdrop-filter на карточках, canvas и обновлений общего контекста плеера. Внедрять оптимизации с проверкой прокрутки, перемотки и загрузки следующей страницы; причина лагов ещё не установлена.
3. OAuth: воспроизвести конкретную ошибку. Текущая кнопка SoundCloud / Google открывает SoundCloud authorization endpoint, отдельного Google OAuth нет. Проверить registered redirect, callback и обмен кода; исправить вводящее в заблуждение описание сохранённого секрета. Не подменять решение отключением защиты браузера.
4. Альбомы: запрос библиотеки явно исключает собственные альбомы (playlists_without_albums), модель Playlist не различает типы релизов. Добавить тип релиза, загрузку и пагинацию альбомов, отдельную навигацию и открытие треклиста. Проверить доступность источников данных до реализации рекомендаций.
5. Главная Discover: горизонтальные ряды обложек, Recently Played, подборки и альбомы; правая колонка лайков/истории по скриншотам. Не выдавать поиск или ленту подписок за персональные рекомендации; доступность Mixes, Stations, Daily Drops и Weekly Wave ещё проверить.
6. Подписки: перенести существующий feed в отдельный экран «Подписки», сохранить обновление, пагинацию и воспроизведение.

Порядок: доступ/единая рабочая копия → воспроизведение лагов и OAuth → модель альбомов → разделение Feed/Discover и оформление.

Готовность: release запускается из меню, интерфейс меняет размер и прокручивается, вход завершает callback, альбом открывается и играет, Feed/Discover имеют разные источники и корректные пустые/ошибочные состояния.
